
# Titanic Survival Predictor Web App

## Features
- Machine Learning Model
- Random Forest Classifier
- Testing Dataset Prediction
- Streamlit Web Application
- Browser-based prediction system

## Install Libraries

pip install -r requirements.txt

## Step 1 - Train Model

python train_model.py

This creates:
titanic_model.pkl

## Step 2 - Run Website

streamlit run app.py

## Open Browser

http://localhost:8501

## Public Deployment

Deploy using:
https://streamlit.io/cloud
